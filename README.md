# Maya Rose Portfolio 📁

My personal portfolio website, with my software engineering projects, my design skills, and a way to get in touch.

## Description

This is my portfolio website, built to show who I am and what I make. It's organized like two paper folders, one for **Software Engineering** and one for **Design**. Clicking a tab brings that folder to the front and changes the background color. Each folder has a short bio, my projects or work, and my skills. At the bottom there is a contact form and links to my social profiles. It uses plain HTML, CSS, and JavaScript, so there is no server to run.


## Features

- Two folders, Software Engineer and Designer, that you switch between with the tabs
- The background changes color to match the folder
- A short bio and a photo of me in each folder
- Project cards with a screenshot, a one-line description, and a link to the code on GitHub (plus a live demo link when the project has one)
- A "What I Use Today" section with my languages, frameworks and runtime, databases and tools, and practices
- A contact form where you choose what your message is about: engineering, design, or just saying hi
- Footer links to GitHub, LinkedIn, X, Bluesky, and email
- A "Skip to portfolio" link and labeled form fields, to make the site easier to use with a keyboard or screen reader
